## 🛠️ How to Use This Library

1. **Follow sequentially** — Days 1–60 build on each other; each file ends with
   a "Next Day Preview" that keeps the thread alive.
2. **Practice, don't just read** — every day has hands-on commands, YAML, and a
   progress tracker. Run them in your own AWS account (clean up clusters after).
3. **When a week ends** — do the week's practice + interview-prep day, then run
   the matching project from [`EKS_PROJECTS.md`](EKS_PROJECTS.md).
4. **Review at milestones** — [`EKS_FOUNDATION_REVIEW.md`](EKS_FOUNDATION_REVIEW.md)
   after Week 4, and
   [Day 60](EKS_Learning/Day-60_Final_Review_Certification_Preparation/README.md)
   carries the full masters blueprint + certification plan.
5. **Need a command fast?** Keep [`EKS_QUICK_REFERENCE.md`](EKS_QUICK_REFERENCE.md) tabbed.
